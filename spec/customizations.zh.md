## 视觉密度

状态：已实现

- 全局会话区域采用更接近桌面客户端的紧凑字号和行高。
- 会话顶部栏压缩为约 40px，减少网页大标题感。
- 左侧栏、工作区行和会话行缩窄并提高信息密度。
- 对话正文区域加宽，减少居中长文章式布局和大块留白。
- Markdown 标题、列表、表格、引用和代码块间距收紧。
- 圆角收敛到 4–8px，减少大胶囊和浮动卡片观感。

## 对话与工具

状态：已实现

- 用户消息弱化气泡感，Assistant 正文更接近连续工作记录。
- Think 与工具调用压缩为单行、可折叠记录。
- 工具详情、Disclosure 行和调用树使用更紧凑的尺寸。
- 空会话的输入区位于底部，保持正常桌面聊天工作流。

## 输入区

状态：已实现

- 输入框改为紧凑矩形、细边框和小圆角。
- 发送按钮使用中性样式，去除明显蓝色大圆按钮和重阴影。
- 输入区字体与正文密度协调，避免网页端的大字号。

## 选中文字批注

状态：已实现

选中 Assistant 回复中的文字会在选择终点旁打开操作菜单，但不影响浏览器复制。选择**添加到对话**后才会在同一终点打开可选评论编辑框，并把被选文本和已填写的批注追加到当前输入草稿。

批注编辑框使用不透明背景和清晰文字颜色。引用加入输入框后，原回复不会保留高亮或引用编号。该功能的实现说明也记录在 `.agents/notes/implemented/feature/2026-08-15-response-selection-annotations.md` 及其中文对应文档中。

## 定制边界

视觉定制应尽量留在 UI 包的 CSS Modules 和现有 slot/组件边界内。文本批注属于独立交互功能，需要保留自己的契约、测试和 Agent Note。任何为了主题而修改 Host、Agent 或持久化协议的做法都需要新的架构决策。
